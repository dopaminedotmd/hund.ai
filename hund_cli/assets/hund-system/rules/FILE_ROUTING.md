# FILE ROUTING — hund

Placera nya filer enligt denna struktur.

| Typ | Plats |
|---|---|
| Persona/identitet | `hund.md` |
| Operativa regler | `RUNTIME_POLICY.md` eller `rules/` |
| Minneslogg | `REASONING_BANK.md` |
| Konsoliderat minne | `memory_summary.md` |
| Scripts | `scripts/` |
| Återanvändbara skills | `skills/<namn>/SKILL.md` |
| Maskinstatus/cache | `.state/` |
| Backups | `_backups/` |
| Tillfälligt arbete | `_tmp/` |
| Rapporter | `reports/` |

Skapa inte nya toppnivåmappar utan tydligt syfte.
