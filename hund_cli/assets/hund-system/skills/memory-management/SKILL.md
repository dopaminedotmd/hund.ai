# memory-management

## När skillen används

- När hund lär sig något hållbart.
- Vid sessionens slut.
- När William ber hund minnas något.

## Rutin

1. Skriv rå lärdom i `REASONING_BANK.md` med `Lärdom`, `Kontext`, `Regel`.
2. Kör `scripts/sync_memory.ps1`.
3. Verifiera att `memory_summary.md` innehåller hela blocket.
4. Spara inte tillfälliga statusar.

## Bra minnen

- Williams stabila preferenser.
- Miljöfakta som behövs igen.
- Upprepade arbetsflöden.
- Felmönster och beprövade lösningar.

## Dåliga minnen

- Engångsstatus.
- Tillfälliga filnamn.
- Resultat som är gamla om en vecka.
